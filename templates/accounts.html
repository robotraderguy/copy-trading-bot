Settings in force

SettingValueWhat it does
COPYING_ENABLED {{ 'on' if copying_enabled else 'off' }} The killswitch. It stops new copies only — it does not cancel orders already placed, and does not close positions already opened.
POLL_SECONDS {{ poll_seconds | int }} Seconds between passes. Each pass costs one broker read per account.
STALE_ORDER_SECONDS {{ stale_order_seconds | int }} Master orders older than this are not copied, so a restart never fires a backlog.
FLASK_SECRET_KEY set Session signing. Its value is never displayed.

Changing any of these means editing .env and restarting the app. That is slower than a button, and it is the honest cost of having no database.
